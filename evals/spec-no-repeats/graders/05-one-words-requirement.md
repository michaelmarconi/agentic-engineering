Two things hold. First, the spec no longer has two requirements that each decide which notes a
search for words shows (the original "Matching notes are shown" and "Notes with every word are
listed"): one was removed or the two were merged, or, if both remain, an open question asks which
to keep. Second, a requirement about which notes the search words show and a separate requirement
about a date range limiting the results both remain: they only meet in the same search and do
not repeat each other.
